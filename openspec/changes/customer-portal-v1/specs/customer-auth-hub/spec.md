## 新增需求

### 需求: 统一客户认证入口
客户门户必须提供统一的认证入口，整合邮箱密码登录、第三方登录与
Passkey 登录方式，并且禁止展示当前系统未启用的登录方式。

#### 场景: 用户查看统一登录入口
- **当** 用户进入客户门户登录页
- **那么** 系统必须在一个统一入口中展示当前可用的登录方式
- **并且** 仅显示系统状态中已启用的方式

#### 场景: 用户使用 Passkey 登录
- **当** 用户设备支持 Passkey 且系统已启用 Passkey 登录
- **那么** 系统必须允许用户直接发起 Passkey 登录
- **并且** 在登录成功后进入客户门户首页

### 需求: 二段式安全验证
当账户启用了 2FA 时，客户门户必须采用独立的二次验证步骤完成认证，
并且在验证成功前禁止访问任何受保护的客户门户内容。

#### 场景: 用户主登录后需要二次验证
- **当** 用户完成主登录流程但账户启用了 2FA
- **那么** 系统必须进入独立的二次验证步骤
- **并且** 在验证通过前不得进入客户门户内容页

#### 场景: 用户完成二次验证
- **当** 用户输入有效的二次验证码并通过校验
- **那么** 系统必须创建完整登录态并放行受保护页面
- **并且** 不要求用户重复执行主登录流程

### 需求: 登录后回跳
当未登录用户访问受保护的客户门户页面时，系统必须在其完成认证后返回
原本意图访问的页面，并且保持必要的导航上下文。

#### 场景: 未登录用户访问受保护页面
- **当** 未登录用户直接访问客户门户内部页面
- **那么** 系统必须把用户引导到统一登录入口
- **并且** 记录其原始访问目标

#### 场景: 用户登录后返回原目标页
- **当** 用户成功完成认证流程
- **那么** 系统必须优先返回用户原本访问的页面
- **并且** 在无原始目标时默认进入客户门户首页
